# @bke/catalog

Reusable BKE Catalog capability for Product and Edition identity, lookup, management, and module-owned PostgreSQL persistence.

Catalog answers **what the product or edition is**. It does not own Commerce pricing/orders, Payments, Entitlements, Licensing, Distribution, or UI.

Standard v0.1.0 kinds: `SOFTWARE`, `SAAS`, `HYBRID`, `SCRIPT`, `DIGITAL_ASSET`.
